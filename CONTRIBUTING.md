# Contributing to TRAMA

Thank you for your interest in TRAMA.

## Before opening a pull request

- Keep the core domain-agnostic: nodes, edges, typed properties, and state channels only.
- Follow the active license and architecture decisions in [`KICKOFF.md`](KICKOFF.md) and [`docs/DECISIONS.md`](docs/DECISIONS.md).
- Do not submit code or assets with incompatible third-party licensing.
- Use a focused conventional commit.

## Contributor agreement

TRAMA must retain the ability to relicense future versions. Before a first pull request is merged, accept the [Individual Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md) by posting its required statement as a comment on that pull request. Maintainers must verify the comment before merging.

Contributions on behalf of an organization require authorization from that organization.

## Pull requests

Explain the problem, keep the diff small, and include the smallest runnable check for non-trivial logic. A pull request is not accepted until its license status is clear.
