# Test networks

`model_full_features.inp` comes from [pyswmm](https://github.com/pyswmm/pyswmm)
(`pyswmm/tests/data/model_full_features.inp`), BSD-2-Clause, © 2014-2025 Bryant E. McDonnell
and the pyswmm authors. It exercises junctions, an outfall, storage, a conduit, a pump and a
weir with cross-sections, plus the hydrology sections this crate deliberately does not read.
