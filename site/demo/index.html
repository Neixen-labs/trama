TRAMA

Suelta tu red y mírala. Se compila aquí, en tu navegador: el archivo no sale de tu equipo.

—

EPANET se ejecuta aquí mismo, compilado a WebAssembly sobre WASI, que es lo que le da el sistema de archivos que su API necesita. Solo funciona con redes importadas de un .inp; para un GeoJSON queda el pulso de demostración, que difunde sobre la topología y sirve para ver el tiempo moverse, no para calcular nada.
