TRAMA

Suelta tu red y mírala. Se compila aquí, en tu navegador: el archivo no sale de tu equipo.

—

La simulación de este playground es un solver de demostración que difunde un pulso por la topología: sirve para ver el tiempo moverse, no para calcular tu red. EPANET necesita un solver local, porque es C con una API de ficheros y el navegador no le da ni libc ni sistema de archivos.
